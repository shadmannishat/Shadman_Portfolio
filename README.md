# Md Salim Shadman — Portfolio

Personal portfolio website: static HTML and images, with no build step.

## Publish on GitHub Pages
1. Create a new public repo named `<your-username>.github.io`.
2. Upload everything in this folder (index.html, blog-post.html, img/, README.md) to the repo root.
3. Settings → Pages → Source: Deploy from a branch → `main` / `(root)` → Save.
4. The site goes live at `https://<your-username>.github.io` in a minute or two.
